2. LOGICA DI ESTRAZIONE DATI (JavaScript/Node.js)
--------------------------------------------------------------------------------
Il protocollo ToneX inserisce un byte di padding (0x88) tra i byte dei dati 
Float32. Le seguenti funzioni filtrano questo byte per una lettura corretta.

A. Lettura Parametri Analogici (Float32):
function readFloat(buf, offset) {
    let bytes = [];
    let i = offset;
    while (bytes.length < 4 && i < buf.length) {
        if (buf[i] !== 0x88) bytes.push(buf[i]);
        i++;
    }
    return bytes.length === 4 ? Buffer.from(bytes).readFloatLE(0) : 0;
}

B. Lettura Stati Logici (Bypass):
function readSwitch(buf, offset) {
    return readFloat(buf, offset) > 0.5;
}

C. Lettura Stringhe (Nome Patch):
function readName(buf, offset, length = 30) {
    return buf.toString('ascii', offset, offset + length)
              .replace(/[^\x20-\x7E]/g, '').trim();
}

4. DIZIONARIO ALGORITMI
--------------------------------------------------------------------------------
REVERB (CC 29):
0: SPRING 1 | 1: SPRING 2 | 2: SPRING 3 | 3: SPRING 4
4: ROOM
5: PLATE

MODULATION (CC 21):
0: CHORUS | 1: TREMOLO | 2: PHASER | 3: FLANGER | 4: ROTARY

DELAY (CC 25):
0: DIGITAL | 1: TAPE

5. NOTE TECNICHE E SINCRONIZZAZIONE
--------------------------------------------------------------------------------
- MIDI SYNC: Per calcolare lo slot (es. 01B), combinare il CC 0 (Bank Select) 
  con il Program Change corrente. 
  Formula: Bank = floor(PC / 3), Letter = PC % 3 (dove 0=A, 1=B, 2=C).
  
- DUMP TRIGGER: Il pedale invia il dump completo solo al cambio patch o quando 
  viene premuto fisicamente il tasto SAVE. Le modifiche ai parametri tramite 
  pomelli non vengono trasmesse via seriale in tempo reale senza un dump.
